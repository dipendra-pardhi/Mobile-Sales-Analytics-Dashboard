# ⭐ Mobile Sales Analytics Dashboard | Power BI Project

> Interactive Power BI dashboard for analyzing mobile sales performance, transactions, customer behavior, payment methods, and regional insights.

---

## 📌 Project Overview

This project focuses on analyzing **mobile sales data** to uncover actionable business insights related to sales performance, transaction trends, customer purchasing behavior, brand performance, and payment preferences.

The dashboard was developed in **Power BI** using a complete analytics workflow including data cleaning, transformation, KPI development, and interactive dashboard design.

This project helps businesses monitor mobile sales performance, identify top-performing brands and cities, understand customer buying patterns, and optimize sales strategies.

---

## 🚀 Tools & Technologies Used

- 📊 **Power BI** – Dashboard Development & Interactive Visualizations
- 📁 **Excel / CSV Dataset** – Raw Sales Data
- 📈 **DAX** – KPI Calculations & Business Metrics
- 🧹 **Power Query** – Data Cleaning & Transformation
- 🗺 **Bing Maps Integration** – Geographic Sales Analysis

---

## 🔄 Project Workflow

### 1️⃣ Data Collection
- Imported mobile sales dataset
- Loaded transactional sales records for analysis

### 2️⃣ Data Cleaning & Transformation
- Cleaned null and inconsistent values
- Standardized mobile brand and model names
- Converted date fields for time analysis
- Structured dataset for dashboard reporting

### 3️⃣ Data Modeling
- Built relationships between tables
- Created optimized data model for better dashboard performance

### 4️⃣ KPI Development (DAX)
Created important business metrics including:

- Total Sales
- Total Quantity Sold
- Total Transactions
- Average Sales Value
- City-wise Sales Performance
- Brand-wise Revenue Analysis
- Payment Method Distribution
- Customer Ratings Analysis
- Day-wise Sales Trends
